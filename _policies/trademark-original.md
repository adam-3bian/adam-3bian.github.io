# Using the CHERI Alliance Trademark
{: .elementor-heading-title .elementor-size-default }

CHERI® is an open technology, but there are conditions to use the CHERI brand, please check the policy, and conform to the guidelines on this page.











## Trademark Policy
{: .elementor-heading-title .elementor-size-default }

The CHERI Alliance Trademark Policy ensures the CHERI name and logos are used accurately and fairly, supporting our mission to advance CHERI technology. It applies to all, even non-members. Certain uses require explicit permission, please check the full document.

For questions or permissions, please [contact us](/alliance/membership/contact/).
