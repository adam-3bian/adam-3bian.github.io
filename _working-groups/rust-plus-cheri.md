# ⚙️ Rust + CHERI WG

Combining memory-safe software and hardware-enforced protection.

The [Rust](/software/rust/) + CHERI Working Group explores how Rust and CHERI can work together to strengthen software security. By combining Rust’s memory-safety guarantees with CHERI’s hardware-enforced memory protection and compartmentalisation capabilities, the group helps advance practical approaches to building more resilient systems.

The Rust software ecosystem page explains the relationships between Rust and CHERI.
