# CHERI Enabled Products
{: id="page-hero-title" .page-hero-title }

The CHERI Alliance's certification program. How products are reviewed, certified, and published.
{: .page-hero-summary }

This page presents the **CHERI Enabled** products up to now.

The [CHERI Enabled programme](https://cheri-alliance.github.io/adopt/assurance-and-adoption/about-cheri-enabled/) provides a structured way to review and document CHERI implementations. Certified products receive a public record describing their scope, supporting evidence, and certification status.

## Certified products
{: id="certified-products" }

The CHERI Enabled product directory contains products certified under the programme. Each entry identifies a specific product and version and publishes the associated certification record.

---

### ![CHERI Enabled logo - 2026](/assets/shared/cheri-enabled-2026/f85dd9d7f416-cheri-enabled-2026.webp){: .image-left .image-inline } Microsoft CHERIoT-Ibex 1.0
{: id="-microsoft-cheriot-ibex-10" }

An open-source 32-bit RISC-V microcontroller processor IP implementing the CHERIoT 1.0 instruction-set architecture. It is designed for constrained embedded systems that require compartmentalisation and memory protection.

The product was certified on **26 March 2026**. The [CHERIoT certification record](https://cheri-alliance.github.io/adopt/assurance-and-adoption/cheri-enabled-products/cheriot-ibex/) covers its architecture, formal verification, test approach, tag protection, temporal-safety model, debug assumptions, and excluded non-CHERI configuration.

---

### ![CHERI Enabled logo - 2026](/assets/shared/cheri-enabled-2026/f85dd9d7f416-cheri-enabled-2026.webp){: .image-left .image-inline } Codasip X730-MP4-Lux 1.0
{: id="-codasip-x730-mp4-lux-10" }

A commercially licensable 64-bit CHERI-RISC-V application processor IP designed for larger systems that require operating-system support and protection of substantial software stacks.

The product was certified on **26 March 2026**. The [X730 certification record](https://cheri-alliance.github.io/adopt/assurance-and-adoption/cheri-enabled-products/x730/) describes its supported modes, hardware verification, memory-access paths, temporal-safety support, debug model, and integration assumptions.
