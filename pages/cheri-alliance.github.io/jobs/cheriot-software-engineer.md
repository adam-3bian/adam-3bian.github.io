# CHERIoT Software Engineer
{: id="page-hero-title" .page-hero-title }

An upcoming, fully remote UK role working across CHERIoT device drivers and secure, compartmentalised software stacks.
{: .page-hero-summary }

This is an early opportunity notice rather than a formal job advert. It describes an upcoming role working on software for CHERIoT, the embedded adaptation of CHERI.

## The work
{: id="the-work" }

The role is expected to combine practical driver development with work higher in the software stack. Initial responsibilities may include:

- turning hardware datasheets and device-class interfaces into working drivers;
- writing and maintaining C++ software, with more of the work expected to move towards Rust;
- designing secure, compartmentalised services and software stacks;
- working across the boundary between embedded hardware interfaces and higher-level system design.

## Who the team would like to hear from
{: id="who-the-team-would-like-to-hear-from" }

The opportunity is open to people with experience in C, C++, or Rust. Junior candidates are explicitly encouraged to express an interest, so applicants do not need to arrive with extensive CHERI or CHERIoT experience.

Experience with embedded systems, low-level software, device drivers, operating systems, or security architecture would all be relevant, but the source post does not present these as a fixed checklist.

## Location and timing
{: id="location-and-timing" }

The role is fully remote but restricted to people based in the UK because of funding requirements. The original post noted that responses and interview arrangements might initially be slower while the hiring manager was unavailable.

No employer name, salary, benefits, employment terms, or closing date were included in the opportunity notice. These details should be confirmed when the formal vacancy is published.
