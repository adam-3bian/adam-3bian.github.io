## Reproduction

Build the starting commit separately into `/tmp/cheri-phase4-before`. Then run from the repository:

```sh
bundle exec jekyll build --destination /tmp/cheri-phase4-site
bundle exec jekyll build --safe --baseurl /cheri-preview --destination /tmp/cheri-phase4-project/cheri-preview
bundle exec jekyll build --source /tmp/cheri-phase4-reference/basic-site --destination /tmp/cheri-phase4-reference-site
python -m unittest discover -s tests -v
bundle exec ruby scripts/check_markdown.rb
python reports/codex-phases/fixture_phase04.py /tmp/cheri-phase4-fixture
bundle exec jekyll build --source /tmp/cheri-phase4-fixture/source --destination /tmp/cheri-phase4-fixture/site/cheri-preview
python reports/codex-phases/audit_phase04.py /tmp/cheri-phase4-before /tmp/cheri-phase4-site /tmp/cheri-phase4-project/cheri-preview
python3 reports/codex-phases/browser_phase04.py /tmp/cheri-phase4-site /tmp/cheri-phase4-reference-site /tmp/cheri-phase4-project /tmp/cheri-phase4-fixture/site
git diff --check
```

Here `sh /workspace/cheri-native-bundle.sh` substitutes for `bundle`; migration Python is `/workspace/cheri-migration-venv/bin/python`, and system Python provides Playwright/Chromium. The fixture requires a new temporary directory. Extract the retained ZIP for the reference build, copy the application's local Poppins into that separate output and replace only its compiled CSS Google Fonts URL with `../shared/fonts/poppins-local.css`. Preserve the tracked Markdown-validator report when running its script. Helpers write only Phase 4 evidence. Production classification uses the native build date in Europe/London; the fixture's date overrides never enter production configuration.
