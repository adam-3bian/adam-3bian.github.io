### It Is Time to Standardize Principles and Practices for Software Memory Safety

Watson, [John Baldwin](/people/john-baldwin/), [Tony Chen](/people/tony-chen/), [David Chisnall](/people/david-chisnall/), [Jessica Clarke](/people/jessica-clarke/), [Brooks Davis](/people/brooks-davis/), [Nathaniel Wesley Filardo](/people/nathaniel-wesley-filardo/), Brett Gutstein, [Graeme Jenkinson](/people/graeme-jenkinson/), [Ben Laurie](/people/ben-laurie/), [Alfredo Mazzinghi](/people/alfredo-mazzinghi/), Simon W. Moore, [Peter G. Neumann](/people/peter-g-neumann/), [Hamed Okhravi](/people/hamed-okhravi/), [Alex Rebert](/people/alex-rebert/), [Alex Richardson](/people/alex-richardson/), [Peter Sewell](/people/peter-sewell/), [Laurence Tratt](/people/laurence-tratt/), [Murali Vijayaraghavan](/people/murali-vijayaraghavan/), [Hugo Vincent](/people/hugo-vincent/), and [Konrad Witaszczyk](/people/konrad-witaszczyk/). Communications of the ACM, 68(2), 2025.

Sets out technology-neutral principles and terminology for specifying and assessing strong software memory safety.
