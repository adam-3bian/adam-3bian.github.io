# Domagoj Stolfa

## Biography

Domagoj Stolfa is a researcher currently working at [Capabilities Limited](/organisations/capabilities-limited/) and [University of Cambridge](/organisations/university-of-cambridge/). He’s done work on kernels, hypervisors, tracing systems and language runtimes. He implemented initial libunwind support for [CheriBSD](/software/cheribsd/)’s c18n and has since been working on V8 and its integration into the Chromium web browser.
