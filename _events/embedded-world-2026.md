## CHERI Alliance presence at Embedded World

One of the advantages of [CHERI Alliance membership](/alliance/membership/membership-benefits-and-options/) is the opportunity to gain visibility at leading industry events. At Embedded World 2026, for the second year, the Alliance welcomed several members to demonstrate their products, technologies, and research on the CHERI Alliance booth, helping showcase the breadth of the ecosystem while creating opportunities for collaboration, business development, and community growth.

![The CHERI Alliance booth at Embedded World - 1](/assets/images/events/embedded-world-2026/ew-2026-1.webp){: .image-full }


## Booth Location

Embedded World Exhibition – Nuremberg Messe – **Hall 5, booth 5-177**

## Demonstrations

| --- | --- | --- |
| [![Capabilities Limited logo](/assets/images/organisation/capabilities-limited.webp){: .image-full }](/organisations/capabilities-limited/) | **CHERI-Enabled CVA6** | Capabilities Limited is working on a CHERI-enabled version of CVA6, a six-stage dual-issue RISC-V processor maintained by the OpenHW Foundation.  We will demo the processor running on a Genesys2 FPGA, showing how we are able to mitigate classic memory safety vulnerabilities in C/C++ applications running on CHERI-enabled operating systems (CheriBSD, CHERI-Linux, and CHERI-seL4). |
| [![The Capable Hub logo](/assets/images/organisation/the-capable-hub.webp){: .image-full }](/organisations/the-capable-hub/) | **CHERI-Enabled RISC-V Open Source Software** | The Capable Hub is working to improve the availability, quality and upstream alignment of open-source CHERI software. We will demonstrate a variety of software including Yocto Linux, Zephyr, and seL4, running on CHERI-enabled RISC-V architecture. We will also demonstrate how our hardware-in-loop infrastructure is improving the quality and test coverage of CHERI software. |
| [![Codasip logo](/assets/images/organisation/codasip.webp){: .image-full }](/organisations/codasip/) | **From Silent Corruption to Safe Fault: CHERI on FreeRTOS** | Using the Codasip Prime CHERI exploration kit, which includes the V739 32-bit CHERI-RISC-V CPU, Codasip will demo an intentionally buggy FreeRTOS application running both without CHERI and in CHERI pure-capability mode, with no changes to the application source code. Three tasks deliberately write beyond buffer bounds. Without CHERI, memory is silently corrupted and execution continues. With CHERI enabled, the out-of-bounds writes are trapped immediately, the fault is handled safely, and corruption of sensitive data is prevented. |
| [![CHERI Research Centre logo](/assets/images/shared/cheri-research-centre.webp){: .image-full }](/organisations/university-of-cambridge/) |  |  |
| [![lowRISC logo](/assets/images/organisation/lowrisc.webp){: .image-full }](/organisations/lowrisc/) | **Sonata platform - CHERIoT features** | A wide variety of demos showcasing the features of the Sonata platform. These demos illustrate how memory safety protection mechanisms can mitigate issues as inspired by real world, observed bugs. The demos highlight how engineers can experiment on resolving real world issues. |
