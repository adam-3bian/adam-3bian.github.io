# 🪁 CHERI Zephyr WG
{: id="page-hero-title" .page-hero-title }

Coordinates CHERI support for Zephyr across architecture ports, kernel and user interfaces, drivers, tooling, and supported platforms.
{: .page-hero-summary }

The CHERI Zephyr Working Group focuses on adapting Zephyr to leverage CHERI’s memory safety and fine-grained protection capabilities, enhancing security for embedded and IoT system.

The [CHERI Zephyr software ecosystem page](/software/cheri-zephyr/) provides the technical overview and links to current public development resources.

Group type
: Technical

Areas of collaboration
: - Zephyr architecture support
  - Memory protection and compartments
  - Drivers, tooling, and platforms
