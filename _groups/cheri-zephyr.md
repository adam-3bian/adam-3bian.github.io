## Overview

The CHERI Zephyr Working Group focuses on adapting Zephyr to leverage CHERI’s memory safety and fine-grained protection capabilities, enhancing security for embedded and IoT system.

The [CHERI Zephyr software ecosystem page](/repositories/cheri-zephyr/) provides the technical overview and links to current public development resources.
