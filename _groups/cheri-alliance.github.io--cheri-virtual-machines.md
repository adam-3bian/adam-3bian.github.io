# 🤖 CHERI Virtual Machines WG
{: id="page-hero-title" .page-hero-title }

Examines how language runtimes, managed environments, and virtual machines can use and preserve CHERI capabilities.
{: .page-hero-summary }

The CHERI Virtual Machines Working Group adapts VMs and language runtimes for CHERI platforms, exploring optimisations for enhanced security and functionality

Group type
: Technical

Areas of collaboration
: - Language runtimes
  - Managed memory and native interfaces
  - Capability-aware VM design
