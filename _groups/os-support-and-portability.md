# 🛠️ OS Support &amp; Portability WG
{: id="page-hero-title" .page-hero-title }

Connects operating-system ports, shared interfaces, terminology, and documentation across CHERI architectures and software projects.
{: .page-hero-summary }

The OS Support &amp; Portability Working Group brings together contributors focused on supporting and documenting the process of adapting both open-source and commercial operating systems for CHERI.

The group aims to publish practical guides, recommendations, and code examples to aid porting efforts, while also acting as a temporary home for work on less common OSes.

In addition, the group collects and shares general insights from OS porting that may benefit the wider CHERI software porting community.

## Relationship to other groups
{: id="relationship-to-other-groups" }

Relevant Alliance groups include [CHERI Linux](/groups/cheri-linux-working-group/), [CHERI FreeRTOS](/groups/cheri-freertos/), [CHERI Zephyr](/groups/cheri-zephyr/), [CHERI for seL4](/groups/cheri-for-sel4/), and [MMU-less Systems](/groups/mmu-less-systems/). Each retains its own technical scope while contributing experience relevant to portability.
