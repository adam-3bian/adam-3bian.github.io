# 🆓 CHERI FreeRTOS WG

Coordinates common approaches to memory protection, compartmentalisation, interfaces, and platform support for FreeRTOS on CHERI systems.

The FreeRTOS Working Group aims to provide a common ground for CHERI-based solutions on FreeRTOS across the Alliance.

Group type: Technical
