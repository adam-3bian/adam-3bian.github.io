# ⚙️ Rust + CHERI WG
{: id="page-hero-title" .page-hero-title }

Combining memory-safe software and hardware-enforced protection.
{: .page-hero-summary }

The Rust + CHERI Working Group explores how Rust and CHERI can work together to strengthen software security. By combining Rust’s memory-safety guarantees with CHERI’s hardware-enforced memory protection and compartmentalisation capabilities, the group helps advance practical approaches to building more resilient systems.

The [Rust software ecosystem page](https://cheri-alliance.github.io/build/software-ecosystem/rust/) explains the relationships between Rust and CHERI.

Group type
: Technical

Areas of collaboration
: - Rust targets and toolchains
  - Native interfaces and unsafe code
  - Platform and runtime support
