# 📋 CHERI + Safety WG
{: id="page-hero-title" .page-hero-title }

Explores how CHERI mechanisms, implementation evidence, and system integration relate to functional safety and assurance needs.
{: .page-hero-summary }

The Safety Working Group focuses on implementing safety standards for CHERI hardware to leverage its memory safety and fine-grained protection capabilities, thereby enhancing the security and safety of safety-critical systems.

Group type
: Technical

Areas of collaboration
: - Safety requirements and claims
  - Implementation evidence
  - Integration and assurance
