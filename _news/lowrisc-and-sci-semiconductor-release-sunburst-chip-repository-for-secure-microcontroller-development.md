[lowRISC C.I.C](/organisations/lowrisc/). and [SCI Semiconductor](/organisations/sci-semiconductor/) have announced the release of the open source **Sunburst Chip** design repository, a major step towards commercialising secure, CHERIoT-Ibex based microcontrollers. This marks a milestone in the DSbD/UKRI-funded [Sunburst Project](https://www.sunburst-project.org/) and supports SCI’s upcoming ICENI family of devices, set for release later in 2025. The repository, now [live on GitHub](https://github.com/lowRISC/sunburst-chip), provides an open source foundation for developers and researchers to explore CHERI-based memory-safe designs. The launch was announced at the [**CHERI Blossoms 2025** conference](https://cheri-alliance.github.io/events/cheri-blossoms-conference-apr-2025/), which highlights the latest in CHERI technology innovation.
