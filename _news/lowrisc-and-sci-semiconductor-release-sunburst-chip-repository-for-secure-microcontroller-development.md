# lowRISC and SCI Semiconductor Release Sunburst Chip Repository for Secure Microcontroller Development

“Open source release accelerates path to market for commercial CHERIoT-based secure microcontrollers, supporting industry adoption and innovation.”

[Gavin Ferris](/people/gavin-ferris/) and [Haydn Povey](/people/haydn-povey/) at the CHERI Blossoms 2025 conference

[lowRISC](/organisations/lowrisc/) C.I.C. and [SCI Semiconductor](/organisations/sci-semiconductor/) have announced the release of the open source Sunburst Chip design repository, a major step towards commercialising secure, [CHERIoT-Ibex](/hardware/cheriot-ibex/) based microcontrollers. This marks a milestone in the DSbD/UKRI-funded Sunburst Project and supports SCI’s upcoming ICENI family of devices, set for release later in 2025. The repository, now live on GitHub, provides an open source foundation for developers and researchers to explore CHERI-based memory-safe designs. The launch was announced at the CHERI Blossoms 2025 conference, which highlights the latest in CHERI technology innovation.
