# The White House promotes CHERI as a solution for memory safety
{: id="page-hero-title" .page-hero-title }

*27 February 2024*{: .source-date }
*Government / Regulation*{: .collection-tag }
{: .collection-detail__metadata }

![The White House promotes CHERI as a solution for memory safety](/assets/news/the-white-house-promotes-cheri-as-a-solution-for-memory-safety/55e2916c5bcf-hero.jpg){: .image-full }
{: .collection-detail__lead-image }

The White House has published a [report](https://bidenwhitehouse.archives.gov/wp-content/uploads/2024/02/Final-ONCD-Technical-Report.pdf) highlighting the need for “securing the building blocks of cyberspace”, that highlights CHERI as a solution that can enable memory safety through hardware features, recognizing that re-writing existing code in memory-safe languages cannot be feasible.

Interestingly, the accompanying [Press Release](https://bidenwhitehouse.archives.gov/oncd/briefing-room/2024/02/26/press-release-technical-report/) highlighted the need for “**shifting the responsibility** of cybersecurity away from individuals and small businesses and **onto large organizations like technology companies**”. The industry cannot ignore this!
