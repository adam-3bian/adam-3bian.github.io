# Earlier acceptance snapshot

This is the historical review of commit `6f05ad4`. The linked simulation, static HTTP, footway and geometry reports have since been regenerated, so their current contents and hashes describe the later build, not this older snapshot. See [the latest handover](../../HANDOVER.md) for current results and open gates. Acceptance remains **incomplete**.

- `npm test`: 72 tests passed. `python -m unittest discover -s tests -p 'route_qa_test.py'`: one test passed. TypeScript checking passed.
- `npm run validate`: both automated CPU journeys completed in the expected station order with no recorded collisions or SPADs; the accelerated two-hour CPU dispatcher soak also completed. See [simulation.json](simulation.json). This is not a two-hour browser/GPU or mixed road/rail traffic soak.
- `npm run build:site` and `npm run verify:site` passed. `python scripts/check-static-http.py` fetched and hash-checked 140 manifest files over local HTTP at both root and nested paths: [static-http-acceptance.json](static-http-acceptance.json). This is not a browser external-request-isolation test.
- `python scripts/route-qa.py --interval 5` returned 1 as intended: 600 candidate source images, zero mapped, zero captured and zero reviewed. It verified source hashes and alignment index, but did not compare the game with the frames.

It failed; mobile-layout and context-loss checks were not reached. See [acceptance-hagley-browser-incomplete.json](acceptance-hagley-browser-incomplete.json).
- A separate current-build Hagley front-view inspection found an apparent footpath/rail conflict. Its source geometry and uncertainty are documented in the [Hagley review](acceptance-hagley-review.md). The issue is not fixed.
- `node --import tsx scripts/audit-footways.ts` returned 1 with 73 **unreviewed lane-level candidates**, including both running lines at Hagley: [footway-crossing-candidates.json](footway-crossing-candidates.json). This centreline screen is not an emitted-triangle intersection audit; candidates may include valid crossings and require source/geometry review.

The [full 121-tile CPU geometry audit](geometry.json) built all tiles and reported zero hard or sampled mandatory failures, but 574 road-surface samples were unmatched, 187 building instances rejected, and 843 cable-attachment candidates unsupported. It recorded 10,800 degenerate triangles without classifying them as hard failures; their locations and impact still require investigation. Finite samples do not certify all scene volumes, and this audit does not close HAG-PATH-001. Independent local recognition, current infrastructure/source fidelity, all-frame paired visual review, whole-route streaming readiness and long-running browser/GPU checks remain open. No RTX 3060 benchmark was run. No screenshots or inferred source records substitute for those gates.
