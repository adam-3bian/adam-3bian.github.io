# Acceptance evidence and open gates

**Acceptance is incomplete.** The railway branch contains a playable implementation and reproducible checks. It must not be described as satisfying every item of `PROMPT.md`, as a surveyed 2026 reconstruction, or as having passed the pending recognition/performance gates. No application was deployed.

The latest targeted visual and HTTP checks are summarised in [current-acceptance.md](reports/current-acceptance.md); its browser run did not complete.

Both failures are retained in [browser-interrupted.json](reports/browser-interrupted.json) and [browser-isolated-interrupted.json](reports/browser-isolated-interrupted.json); they are not counted as successful full capture runs or as evidence of a WebGL failure. IndexedDB persistence was tested separately in [storage-browser.json](reports/storage-browser.json), including a 6 MiB payload rejected by localStorage, reload preservation and legacy migration. Software rendering flags are test-environment settings, not product requirements or hardware-performance evidence. The two-hour browser gate remains pending.

The archived 44-view report retains its original source and build hashes; it cannot establish acceptance of the current WebGL renderer.
