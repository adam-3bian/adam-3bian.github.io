# Acceptance evidence and open gates

**Acceptance is incomplete.** The railway branch contains a playable implementation and reproducible checks. It must not be described as satisfying every item of `PROMPT.md`, as a surveyed 2026 reconstruction, or as having passed the pending recognition/performance gates. No application was deployed.

## Measured evidence

| Area | Evidence and limit |
| --- | --- |
| Route and driving | Both full normal passenger journeys call at all 21 destinations after the origin, covering the 22 ordered stations. The deterministic driver uses the normal controller and shared signals; see [reports/simulation.json](reports/simulation.json). These are accelerated CPU runs. |
| Controls and protection | All 68 tests pass; [unit-tests.json](reports/unit-tests.json) records counts and source hashes. Coverage includes A/D rate/hold/simultaneous commands, traction cut by safety demand, AWS acknowledgement/timeout, Q versus TPWS reset, swept OSS/TSS receiver timing, wrong-track/direction non-triggers, full-consist occupation, point locking, physical reversal, canted support and actual graded cable-trough contact. Browser keyboard events and save/reload are recorded separately. T is unassigned. |
| WebGL rendering | The earlier [WebGL browser run](reports/webgl-browser.json) passed 16 assertions, including actual framebuffer pixels, controls, large saves, reload and mobile layout. It recorded front views in both directions at eight selected stations, plus normal/reverse point views; human recognition and point-readability review remain pending. Earlier [endpoint checks](reports/webgl-endpoint-browser.json) exercised train visibility at both route boundaries and automatic saving after context loss. These source-hashed captures predate the menu and resolution changes. |
| Menu and render resolution | The [current static-site browser check](reports/display-settings-browser.json) verifies 50%, 75% and 100% actual WebGL drawing-buffer sizes, independent scenery quality, resize, preference persistence, pause-menu settings and continuation of a real save from the previous WebGL site. It used software WebGL 2 with WebGPU disabled; pixel counts do not prove an FPS gain or hardware-performance acceptance. |
| Rendering history | The former WebGPU [44-view scene snapshot](reports/browser-scene-snapshot.json) passes all 15 browser assertions. It predates endpoint-culling and static-hosting corrections and does not establish WebGL presentation or hardware performance. Current WebGL browser checks are recorded separately below. |
| Static hosting | The earlier [webgl-static-site.json](reports/webgl-static-site.json) exercised static HTTP servers at the web root, a nested path and the repository-root entry, and continuing a same-origin WebGPU save. The current display check uses a nested static site with outside requests blocked and continues a previous WebGL save. The [integrity check](reports/static-integrity.json) describes an earlier package; `npm run verify:site` verifies the current build against its manifest. The bundled site needs no npm or Node server. |
| Procedural geometry | The previous full [geometry.json](reports/geometry.json) audit built all 121 tiles without reported hard or sampled mandatory failures. It measured 11,574 running-gauge sections (maximum error 1.366 mm), resolved all 7,035 neighboring building-support queries and found no measured road/ballast terrain intrusion. It retains 574 unmatched road-surface samples, 187 rejected building placements and 843 unsupported cable attachments as uncertified/unaccepted coverage. The [WebGL equivalence check](reports/webgl-geometry-equivalence.json) verifies unchanged audit inputs apart from shared Three.js import changes, an identical scenery worker, and matching generated geometry for four representative tiles. It does not rerun the full audit or certify continuous scene volumes or complete asset fidelity. |
| Asset identity | [reports/placed-assets.json](reports/placed-assets.json) inventories emitted static placements and tree roots with source hashes. Ribbon components and dynamic renderer instances have generator metadata but are outside that inventory's stated coverage. |
| References | All 2,995 inventoried uploaded reference files were checked against their SHA-256 values with zero changes; see [reference-integrity.json](reports/reference-integrity.json). Expanded frames remain indexed at one second and original frames at five seconds. |
| Geometry budgets | All thirteen declared factory probes meet their LOD0 triangle targets; [asset-budgets.json](reports/asset-budgets.json) records parameters and counts. This does not establish complete LOD contracts or the hardware frame-rate target. |

Two earlier WebGPU SwiftShader capture attempts lost the device with `A valid external Instance reference no longer exists`, including an isolated attempt. Both failures are retained in [browser-interrupted.json](reports/browser-interrupted.json) and [browser-isolated-interrupted.json](reports/browser-isolated-interrupted.json); they are not counted as successful full capture runs or as evidence of a WebGL failure. The app paused and attempted an automatic save; the last complete saved state was not inspected in those failed runs. IndexedDB persistence was tested separately in [storage-browser.json](reports/storage-browser.json), including a 6 MiB payload rejected by localStorage, reload preservation and legacy migration. Software rendering flags are test-environment settings, not product requirements or hardware-performance evidence. The two-hour browser gate remains pending.

The archived 44-view report retains its original source and build hashes; it cannot establish acceptance of the current WebGL renderer.
