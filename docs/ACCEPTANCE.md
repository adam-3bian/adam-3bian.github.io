# Acceptance evidence and open gates

**Acceptance is incomplete.** The railway branch contains a playable implementation and reproducible checks. It must not be described as satisfying every item of `PROMPT.md`, as a surveyed 2026 reconstruction, or as having passed the pending recognition/performance gates. No application was deployed.

## Measured evidence

| Area | Evidence and limit |
| --- | --- |
| Route and driving | Both full normal passenger journeys call at all 21 destinations after the origin, covering the 22 ordered stations. The deterministic driver uses the normal controller and shared signals; see [reports/simulation.json](reports/simulation.json). These are accelerated CPU runs. |
| Controls and protection | All 66 tests pass; [unit-tests.json](reports/unit-tests.json) records counts and source hashes. Coverage includes A/D rate/hold/simultaneous commands, traction cut by safety demand, AWS acknowledgement/timeout, Q versus TPWS reset, swept OSS/TSS receiver timing, wrong-track/direction non-triggers, full-consist occupation, point locking, physical reversal, canted support and actual graded cable-trough contact. Browser keyboard events and save/reload are recorded separately. T is unassigned. |
| Native rendering | The [44-view scene snapshot](reports/browser-scene-snapshot.json) passes all 15 browser assertions, including exact controls, mobile layout, save/reload and intentional device loss. A subsequent renderer-only correction keeps AI visible until the full consist clears the route boundary. Fresh [production smoke](reports/production-browser.json) and [endpoint checks](reports/endpoint-browser.json) pass on that final build; the endpoint check also proves automatic saving of a new safety-brake state after device loss. Exact source/build hashes distinguish these snapshots. Software WebGPU results do not establish RTX 3060 performance. |
| Procedural geometry | All 121 tiles built with no reported hard or sampled mandatory failures. Actual probes measured 11,574 running-gauge sections (maximum error 1.366 mm), resolved all 7,035 neighboring building-support queries and found no measured road/ballast terrain intrusion. [geometry.json](reports/geometry.json) retains 574 unmatched road-surface samples, 187 rejected building placements and 843 unsupported cable attachments as uncertified/unaccepted coverage. This is not a continuous whole-scene volume or full asset-fidelity certificate. |
| Asset identity | [reports/placed-assets.json](reports/placed-assets.json) inventories emitted static placements and tree roots with source hashes. Ribbon components and dynamic renderer instances have generator metadata but are outside that inventory's stated coverage. |
| References | All 2,995 inventoried uploaded reference files were checked against their SHA-256 values with zero changes; see [reference-integrity.json](reports/reference-integrity.json). Expanded frames remain indexed at one second and original frames at five seconds. |
| Geometry budgets | All thirteen declared factory probes meet their LOD0 triangle targets; [asset-budgets.json](reports/asset-budgets.json) records parameters and counts. This does not establish complete LOD contracts or the hardware frame-rate target. |

Two earlier SwiftShader capture attempts lost the device with `A valid external Instance reference no longer exists`, including an isolated attempt. Both actual failures are retained in [browser-interrupted.json](reports/browser-interrupted.json) and [browser-isolated-interrupted.json](reports/browser-isolated-interrupted.json); they are not counted as successful full capture runs. The app paused and attempted an automatic save; the last complete saved state was not inspected in those failed runs. IndexedDB persistence is tested separately in [storage-browser.json](reports/storage-browser.json), including a 6 MiB payload rejected by localStorage, reload preservation and legacy migration. The software-only test flags now disable Chromium's GPU watchdog, following the Three.js project's [WebGPU screenshot CI investigation](https://github.com/mrdoob/three.js/issues/33559). This is a test-environment setting, not a product requirement or proof of the specific loss cause. The final report records the flags and its own results; the two-hour browser gate remains pending.

The archived 44-view report predates only the final occupied-interval culling correction. Static geometry, route data, controls, simulation and persistence did not change afterward. Those captures retain their original hashes; the final renderer's endpoint evidence is recorded separately rather than silently inheriting a full capture pass.
