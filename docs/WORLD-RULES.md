# Shared construction rules: implemented scope and remaining work

The November 2026 grid-world revision is described in [GRID-WORLD.md](GRID-WORLD.md). Its integer construction addresses, smooth rail curves, complete-world persistence and explicit site bindings supersede the earlier storage description below. The [location manifest](../references/location-reference-manifest.json) governs geometry changes. SVR scope is Kidderminster scenery only.

The current reconstruction applies OpenLoco/Locomotion's separation of logical objects, connected transport paths, construction validation and rendering to the continuously mapped UK route. A spatial tile is an index and render owner, not a square-grid construction constraint. Source X/Z geometry is preserved; deck/stair profiles and foundation levels remain explicit model engineering where the supplied heights are bare-earth estimates.

`src/world/site-definitions.json` separates evidenced site instances from reusable generators. `access-sites.ts` resolves a whole declared deck/stair assembly before mesh emission; `road-sites.ts` resolves the connected span and both road approaches before terrain grading. The same engineered motor-road profile is consumed by simulation and terrain/road mesh generation. These definitions and solvers participate in the world/save identity and geometry-audit source hashes.

| Rule | Current executable application | Evidence and limit |
| --- | --- | --- |
| JOIN-01 | All declared stair paths must meet their deck in plan within 10 mm. Brake Lane's two source road joins must agree within 10 mm before reprofiling; the shared solution returns identical endpoint elevations. Missing required assembly members fail generation. | `tests/access-sites.test.ts`; exact model joins do not imply survey precision. |
| SUPPORT-01 | Stair feet select the intended station platform, with bounded station/lateral containment. Risers and goings derive from that level. Deck posts have platform contacts and ground-to-platform plinths; an arch has four foundation anchors. | Actual stair landing errors and complete-source replacement are measured by `scripts/audit-hagley-access.ts`. Exhaustive support/footprint and all-site validation remain open. |
| LAYER-01 | Hagley footway and step IDs are retained as one elevated access assembly, replacing their ground-road representation and the duplicate generic footbridge. Brake Lane's elevated road and arch retain the two running lines below. | Complete emitted assembly inventory retains original IDs and reference/confidence. Unknown footway crossings are not automatically elevated. |
| CLEARANCE-01 | Both running lanes and finite body-width samples through the footbridge/arch are ray-tested against actual emitted triangles. The masonry arch is sheared to the mapped road skew while its bore follows the railway. | This is a finite regression; it is not a continuous full-consist swept-volume certificate. |
| TERRAIN-01 | Existing shared terrain grading consumes the same solved span/approach profiles, and terrain does not fill the declared open span. | Full 121-tile audit and bridge regression remain finite. Continuous triangle clipping across all roads/structures is still incomplete. |
| STATE-01 / REGEN-01 | Motor-road population/state remains in the simulation, not render chunks. A site definition/source change changes world identity. Named reference copies retain original bytes; renderer resizing does not change world state. | Existing deterministic traffic and new viewport tests. Whole-world command replay and transactional replacement remain incomplete. |

Current bounds: 190 mm maximum designed riser, 250 mm minimum going, 1.05 m handrails, 300 mm access deck thickness and an inferred 5.25 m deck height above local rail. Brake Lane uses an inferred 6.3 m road deck rise and 100 m transition length. These are declared model choices, not verified site dimensions. Contact tolerances are separate from source confidence. Asset components include solid decks, stair treads/support, parapets/handrails/lattice, roofs, posts, foundations, arch barrel/spandrels and road approaches.

The full shared executable registry, world-element stacks, validated command/replay boundary, coherent transactions across every asset family, all-site support/volume tests, clearance graphs, source-exact crossing control sites, continuous-drive readiness, vehicle lifecycle and comprehensive reference acceptance are **not complete**. The governing completion requirements remain in `WORLD_RULES_PROMPT.md` and `FINISHING_PROMPT.md`.
