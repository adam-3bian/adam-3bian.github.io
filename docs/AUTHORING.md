# Authoring the CHERI site

The maintained developer and publisher guide is
[pages/publishers.md](../pages/publishers.md), served at `/publishers/`.
It is unlisted and has no menu entry.

Start there for Markdown editing, links, left/right/full-width images, common
front matter, every active collection, pages and directories, asset preparation,
and local verification. Examples follow the current native Kramdown/Jekyll
templates and validation rules.

Focused references:

- [Site assets](assets/README.md): file ownership, image ratios and preparation.
- [Event programmes](event-programme.md): nested speakers and media, without authored IDs.
- [People](people.md): main and additional affiliations, roles and card labels.
- [Design rules](DESIGN_SYSTEM.md): shared presentation and responsive behaviour.

Edit content records rather than historical migration snapshots or rendered
output. For this design work, use `design/catalogue-polish` exclusively.
