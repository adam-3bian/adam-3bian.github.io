# Catalogue design review

The current implementation, measured outcomes and checks are documented in [the refinement review](REFINEMENT_REVIEW.md). [Shared component rules](DESIGN_SYSTEM.md) and [the authoring guide](AUTHORING.md) describe the supported design and Markdown model.

The preceding pass, `7273a61`, established opaque reading surfaces, the navigation-card versus passive-panel contract, consistent focus treatment and accessible glossary controls. The current refinement retains those foundations and replaces the former card excerpts, glossary presentation, image proportions and sparse facts panels.

[Earlier before/after screenshots](screenshots/catalogue-polish/README.md) retain the historical comparison for that pass. [Current screenshots](screenshots/catalogue-refinement/README.md) cover the latest desktop, tablet and mobile design.
